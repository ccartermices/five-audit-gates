# 医生标注协议 v1.0（CM 队列弦/非弦盲判，2026-11-03）

**一句话**：AI 盲预标注（56 人：弦 7 / 非弦 9 / 边界 40）已产出，医生对
56 张盲判波形图做二选一判读（每人 <1 小时）；医生**必须盲判**——不展示
AI 预标注、不给年龄/血压。医生盲判标签是外部效度的验证靶子，AI 预标注
只用于困难例排序与事后一致性分析，二者物理分离。

---

## 1. 背景与定位（为什么这样设计）

用户决策（2026-11-03）：「AI 先标注，医生再检查」。该方案的效度取决于
**医生盲判**：

- 若医生先看 AI 标签再确认 → 锚定效应，医生沦为 ratifier，论文只能写
  "AI-assisted annotation with physician review"，与「AI 自标自验」的
  循环论证无实质区别；
- 医生**盲判**后，医生标签独立于特征工程管线，L1→医生标签 的相关才是
  真正的外部效度证据（12 号 §4 的边界由此可再收窄）。

**诚实定位（论文中不得过度声明）**：医生标注对象是波形图，非原位触诊。
其价值是（a）共识标准、（b）构建者独立——**不**声称提供触觉通道
（脉位/脉宽/力度）信息。GAPS 中「洪/细、浮/沉不可测」不因此关闭。

## 3. AI 预标注规则（预注册 v2，医生返回前冻结）

量均为人级（56 人）中位数聚合的稳健 z 分（z=(x−median)/1.4826·MAD）。

- **R1 反射规则**：s1 = mean_z(notch_depth, −sdptg_b, kurt)。
  切迹深/早期反射 b 深/峰锐（「端直以长，如按琴弦」）= 弦向。
- **R2 重搏规则**：s2 = −sdptg_d_z。d 波越深越「滑」。
- 判据：s1、s2 各按三分位——上 1/3 端位、下 1/3 反端位、中间边界。
- 融合：R1/R2 同向 → 该向（高置信 16 人）；冲突或任一侧边界 → 边界
  （低置信 40 人）。

**版本史（判后不得再调）**：v1 用 |z|≥0.5 阈值且含 p2_rel，结果 52/56
落入边界（复合均分摊平 z 尺度；CM 段级 P2 检出率仅 76.5%，人级中位数
过半 nan）。v2 改分位数三分类、R1 剔除 p2_rel 加入 kurt。**边界占 71%
是诚实结果**：两规则在 CM 的 10 Hz 带宽下本质分歧，与 19 号「CM 弦/滑
L1 不可验证」一致——这正说明医生盲判的必要性，不是 bug。

## 4. 医生判读任务

1. 看图（`figs/prelabel/`，按编号顺序），每张回答：
   - 判读：**弦 / 非弦**（二选一，强制）；
   - 置信度：1=不确定、2=较确定、3=确定；
   - 备注（可选）：不确定的原因（如"切迹看不清"）。
2. 每人独立判读，两位医生**不得互相讨论**（各自填一张表）。
3. 全部 56 例都判，不跳过；预计每人 <1 小时。
4. 表格填完交回 `physician_annotation_form_<医生名>.csv`。

**给医生的一页说明**（可直接转发）：弦脉要点「端直以长、如按琴弦」，
波形上表现为峰尖锐、重搏波不明显；非弦（含滑/平） waveform 更圆滑、
重搏结构更明显。仅依据图形形态判断，不知道任何临床信息。

## 5. 返回后的分析计划（预注册）

1. **医生间一致性**：两位医生的 Cohen's κ。κ<0.4 → 共识不足，只报
   一致性结果并停止下游（诚实失败优于勉强结论）；0.4–0.6 → 仅用双医
   生一致的子集；≥0.6 → 全集 + 分歧例标记。
2. **AI vs 医生**：预标注一致率 + κ（分高/低置信分层）。AI 预标注
   与医生不一致的例单独列表——它们是 L1 特征与医生判断的分歧点，
   是讨论章节最有价值的材料。
3. **外部效度锚点（主分析）**：L1 30 量（人级）→ 医生共识标签的
   人级判别：单量 AUC + 嵌套 LOOCV（同 19 号协议，不许按行分折），
   报告点估计 + 自助区间。**预期不高**（CM 带宽限制），任何正结果
   都构成「L1 携带脉型信息」的第一笔人类专家证据。
4. 措辞上限：无论结果如何，均按 21 号口径 —— "consistent with,
   but not establishing"。

## 6. 局限（论文 Limitation 段必写）

- 标注对象为波形图，非原位触诊，不覆盖触觉通道维度；
- 56 人单中心队列，判读结论仅对本队列成立；
- 弦/非弦二分强制，混合脉型（弦滑相兼）只能进「非弦」或按备注单独分析；
- AI 预标注与 L1 同源，其一致率不构成独立证据（仅用于分歧例挖掘）。
