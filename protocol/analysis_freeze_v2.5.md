## 2. 新增条目

### G16 校准必报（硬约束）

任何输出决策或概率的模型，报告必须同时包含：

1. **ECE**（10 bin）与 **Brier**，且给出 bootstrap 95% CI；
2. **可靠性曲线**（预测概率 vs 实际阳性率），不得只给单一标量；
3. **与训练域先验基线的对照**（`const_prior`：noul 用阳性率、score 用档位直方图）；
4. 若报告 AUC，须声明 AUC 与校准可能背离——本项目中已出现"ECE 0.016 但 AUC 0.705"与"ECE 0.409 但 AUC 0.518"两类组合。

理由：07 的 G15 只拦"不如常数"这一种失败；实测还存在"优于常数但校准完全失效"（08 §7.4）与"校准极好但判别为零"两种情形，单一指标无法区分。

### G17 缺失不得填补

异构数据源的特征必须以「值 + 存在掩码」表达，**禁止**均值/中位数/回归填补参与跨源比较或域可分性评估。

理由（08 §5）：MIMIC 的 `age`/`sex` 覆盖率为 0，06/07 用训练集中位数填补后，该列在 MIMIC 上变成**完全等于填补值的常量**，构成完美域指纹。这会把域可分性系统性高估，同时给 425 个受试者伪造一个人口学输入。PWDB 的 `n_beats=40` / `beat_consistency=1.0` / `valid_frac=1.0` 属同类问题（仿真单周期无搏级统计量，值为占位常数）。

例外：单一域内部的插值（如同一受试者相邻周期之间）不受此限，但必须显式标注。

### G18 契约自证检查

任何 `choice` / 多分类任务在报告准确率前，必须确认答案字段**不在输入中**。

- 若答案字段在输入中（如把 `provenance.source` 放进 state 再问"这是哪个队列"），结果只能标为**自证上界**（本项目实测 0.9998），不得作为性能。
- 真正的可分性检验必须只给特征，实测纯形态 0.9905、加冻结潜 3 维 0.9967（08 §7.3）。

### G19 跨域校准须报 k 曲线

跨域部署（或任何训练/目标域基础率不同）的情形，必须报 k-shot 校准曲线，并**至少比较两种策略**：

- **先验替换**（1 参数：用 k 个标签的经验率替换输出先验）；
- **Platt / 温度缩放**（2 参数）。

并说明在 k 较小（≤10）时选哪个。理由（08 §7.5）：VDB 上 k=5 时先验替换把 ECE 从 0.206 降到 0.088，而 Platt 反而升到 0.302——两参数用 5 个点估必然噪声爆炸。

### G20 异构表征的域不变性须单独检验

不得因"表征维度低"或"训练目标与标签无关"而假定表征是域不变的。必须直接测：把该表征加入纯形态输入后，域可分性（choice 探针准确率 / 平衡准确率）是升还是降。

理由（08 §7.3）：冻结的 PWDB 瓶颈 AE（k=3）加入后，四源可分性从 0.9905 升到 0.9967，CM 召回从 0.667 升到 0.877——**它放大域签名而非消除**。

## 4. 对论文主张的影响（本轮）

**加强的：**

1. "四源不可混"从单一证据变双路径证据：走掩码 state + choice primitive、无任何填补，仍 99.05% 可分。
2. "高血压代理标签不成立"第四次复现，且这次在一个**校准良好**的模型上（M0：Brier 0.197 < 常数 0.221，ECE 0.016）——排除了"模型没训好"的替代解释。
3. "CM 的形态不可用"定量化：SBP 档位 CRPS 比常数先验差 0.46，是四源唯一为负。

**修正的：**

1. 06 的域分类 AUC = 1.000 **可能含填补伪影**；本文件的 0.9905 才是干净估计。方向性结论不变。
2. 06 的负迁移主因不是"特征不可比"，而是**基础率差**（0.2% / 33% / 47%）；5 个目标域标签即可把 ECE 从 0.206 降到 0.088。
3. 07 的"JEPA 更省"作废；"k=3 最小配置"保留但不得称其为域不变表征。

**新增可发表的方法学结论：**

4. **校准的跨域失效是可分的**：判别失效（AUC→0.5）与校准失效（ECE→0.41）同源但可分别修补，且修补校准只需 5 个标签、修补判别需要新信息。这条把"迁移失败"从一个笼统结论拆成两个可操作的子问题。
