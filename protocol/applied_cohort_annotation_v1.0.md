# 真实队列（CM）标注规程 v1.1

> 适用对象：受邀参与标注的中医师 / 临床医生，以及负责数据交接的工程侧。
> 目的：把"请医生标注"这件事变成可验收的工序，而不是一次口头协作。
> 冻结日期：2026-11-02（v1.1 修订：接入波形前处理与质量门，见 `13_真实队列前处理_20261102.md`）。
> 凡改动字段或判据，必须升版本号并重跑 `check_annotation.py`。

---

## 0 一句话结论（请先读这一段）

**在本队列上补血压标注救不了训练；补脉象判读才有价值。**

但原因要说准。v1.0 曾把"训不动"归因于"人内变异压过人间变异"，**该归因已撤回**：
那是波形未做前处理造成的伪影。清洗后（`13` 号）`upstroke_slope` 的人内/人间 SD 比
从 1.88× 降到 **0.88×**，六部之间确实含有人体信息。

真正卡住的是两点，与医生的标注质量无关：

1. **每人只有一次血压**。六部是同一时刻的位置重复（左右手相隔中位 18 min），
   没有可供学习的时间变异；18 min 内血压变化 <5 mmHg，而人间 SD 约 25 mmHg。
2. **n=57 撑不起多变量**。清洗后单量最强 ρ=0.39（`h1`）、0.38（`kurt`），
   超 5% 显著阈（|ρ|≈0.26）；但 35 量 Ridge 的人级留一交叉验证只有 **ρ=0.080**。

医生在这个队列上**唯一不可替代、且现在就能做**的贡献是：**六部脉象盲评**——给 57 人 ×
6 部（左右寸关尺）一个真实的弦/滑/平/涩判读。现有标签是"血压≥140 就当弦脉"的机器代理
（`is_proxy=1`，置信度栏写着"低（无医师判读）"），这是整个中医分支最大的真值缺口。

如果一定要"逐搏血压"，只有一条路：**前瞻重采**（第 5 节），回顾数据上不存在这种标注。

## 1 三个硬事实（先看数字，再谈方案）

### 1.1 334 段是"位置重复"，不是"时间重复"

| 事实 | 数值 | 出处 |
|---|---|---|
| 受试者 / 原始段数 | 57 人 / **335 段**（另有 57 条 `Z<ID>_cell` 传感器置零记录，不计） | 压缩包 `Cell Matrix/` |
| 通过质量门的段 | **294 段（88%）**，覆盖 56 人；`SUBJ-B` 六段全未过门 | `data/cm_quality.csv` |
| 每人段数 | 6 段 32 人、5 段 15 人、4 段 2 人、3 段 5 人、2 段 2 人（指可用段） | 同上 |
| 段编号 | L1–L3（左手寸关尺）、R1–R3（右手寸关尺）、少量 LL1/LL3 | 同上 |
| 每段时长 / 采样率 | 168 s / **50 Hz**（由 `.dat` 的 Time 列步长 20 ms 反推；`<ID>.TXT` 里的 128 Hz 属另一台张力计，勿混用） | `real_preproc.py` |
| 左手段结束 → 右手段开始 | 中位 **18.1 min**（四分位 14.3–22.2，全距 10–31） | 原始 `.dat` 文件名时间戳 |

也就是说：同一个人 6 段波形，是**同一时刻在六个部位**各采一次（左右手相隔约 18 分钟），
不是同一个人在不同时间被反复测量。**没有时间维度，就没有血压变化可供学习。**

### 1.2 每人只有 1 个血压，且是代理标签

- 血压来自血压脉波检测仪导出表的 `SP/DP` 字段（每人 1 条记录，`DATETIME` 齐全，
  如 `SUBJ-A`：2015-10-13 15:47:13，SP 184 / DP 104）。
- 100 条仪器记录里，99 条是"每人 1 条"；没有同一人的重复测压。
- `labels_master.csv` 的 `label=弦脉` 全部由 `SBP>=140 or DBP>=90` 规则生成，
  `is_proxy=1`，`confidence=低（无医师判读，仅为血压阈值代理）`。

### 1.3 人内变异并不压过人间变异（v1.0 的归因已撤回）

v1.0 用未清洗波形算出人内/人间 SD 比 1.88–2.09×，据此判定"任务定义本身没有可学信号"。
接入前处理后该结论不成立——旧版把量化台阶与基线残差算进了"部位差异"：

| 形态量 | 旧比值（未清洗） | 新比值（清洗后，294 段） |
|---|---|---|
| `upstroke_slope` | 1.88× | **0.88×** |
| `notch_depth` | 2.09× | **1.32×** |
| `width50` | 1.23× | 0.75× |
| `h3_r` | 0.87× | 0.70× |

清洗后 `upstroke_slope` 的人内变异**小于**人间变异，说明六部差异里含有人体信息。
卡点因此从"信号脏"改为"标签少 + 样本少"：

| 检验 | 结果 |
|---|---|
| 人级单量最强 | `h1` ρ=0.392、`kurt` −0.376、`h3_r` −0.285 |
| 人级多变量（35 量 Ridge，留一） | **ρ=0.080** |
| n=57 的 5% 显著阈 | |ρ|≈0.26；35 个量中仅 5 个过阈，且都是幅度/谱描述量 |

> T1（补逐次血压）仍然不值得做：只有左手段/右手段两个时点（相隔 18 min），
> 18 min 内血压变化 <5 mmHg，而人间 SD 约 25 mmHg。**补了仍是噪声。**

## 2 四档任务：哪一档值得做

| 档 | 任务 | 能否解决"CM 训不动" | 医生工时 | 产物 | 建议 |
|---|---|---|---|---|---|
| **T0** | 标签审计：核对 57 条 SP/DP 的测量条件 | 否（只提高标签可信度） | 0.5 天 | `A0_bp_audit.csv` | **做**，成本极低 |
| **T1** | 逐次血压摘录：查病历补同日/同次就诊的所有测压值 | 否（时点最多 2 个，差值太小） | 1–2 天 | `A1_bp_session.csv` | 可做，但**不要指望它救训练** |
| **T2** | **六部脉象盲评**（弦/滑/平/涩…） | **是，但换的是任务**：从"预测血压"变成"预测脉象" | 3–5 天 | `A2_pulse_read.csv` | **主任务，优先启动** |
| **T3** | 前瞻逐搏：同步连续血压 + 六部波形 | **是**（唯一能得到逐搏标签的路径） | 4–6 周（含伦理） | 逐搏标签 + 新波形 | 需伦理修正案与设备，见 §5 |

**关键提醒**：T2 不是"给血压任务补标签"，而是把研究问题换成"模型能不能读出医生读出的脉象"。
这条路上的真值只有医生能给，而且它直接对应项目最初的问题——"AI 是怎么想中医的、想得对不对"。

## 3 T2 主任务：六部脉象盲评（现在就启动）

### Step 1 伦理与数据边界（1 次会，30 min）

1. 确认现有两份伦理批件（`A-BR-100-166`、`B-ER-103-263`）覆盖"对已采集波形做回顾性判读"。
   回顾性判读通常不构成新的人体研究，但**判读者若署名作者，须列入研究团队**。
2. 明确数据出科室规则：只出**匿名波形图**（`P01`–`P57`），不出姓名、出生日期、住院号、血压。
3. 签一份《判读者承诺》：不尝试反推受试者身份、不将图像外传、判读期间不看临床资料。

### Step 2 生成标注包（工程侧，0.5 天）

产出 `annotation/packets_v2/`（**已生成 294 张**；旧 `packets/` 用未清洗波形，停用）：

```
P01_A.png ... P57_F.png      每部一张，12 s 清洗波形，1 s 细网格，无任何文字标注
packets_v2/manifest.csv      判读清单（含被剔除段的 why，避免判读者以为漏发）
key.csv                      匿名号 → 真实 subject_id + 部位 + 通道 + 质量指标（仅工程侧）
templates/A2_pulse_read.csv  判读结果模板
```

**只出通过质量门的段**：低信噪/掉线段出图等于让医生对噪声做判读，
会系统性污染一致性统计。本轮 335 段中 294 段可用（88%），41 段剔除。

要求：
- 图像**不含**患者姓名、日期、年龄、性别、血压，也不用 `L1`/`R1` 这类会暴露"寸关尺"的编号（用 `P01_A` 六字母随机码）。
- 波形纵轴统一归一化并**隐藏刻度**，不加 mmHg（否则会泄露血压量级）。去基线后波形零均值，幅度不携带绝对血压信息。
- 每人六部的顺序**随机打乱**后再编号，避免"寸关尺"位置先验影响判读。

### Step 3 判读培训（1 次，60 min）

1. 用 10 例**非本研究**的示例波形讲清判读口径（避免用样本内病例，防止泄漏）。
2. 明确 8 个字段怎么填（见 §3.1 编码字典），特别是"主脉只能选一个"。
3. 练手 20 例，当场对答案、统一分歧，再进正式判读。

### Step 4 正式判读（3–5 天，每天 ≤2 h，避免疲劳）

- 盲法：判读者**不知道**任何人的血压、年龄、既往诊断。
- 顺序：按 `index.csv` 的随机序号，不做分组。
- 双读：随机抽 **20%（12 人）** 由第二位医师独立判读，用于算一致性。
- 自身重测：同一医师 **2 周后**重读 10%（6 人），用于算判读者稳定性。

### Step 5 回收与质检（工程侧，0.5 天）

$PY scripts/check_annotation.py --task pulse     # 完整性/取值域/重复标注/κ

### Step 6 入库与重跑（工程侧，1 天）

- 把 `A2_pulse_read.csv` 接成 CM 的第二套标签（`label_type=tcm_pulse_physician`，
  `is_proxy=0`），替换现有阈值代理。
- 用 `probe_mediator.py --sources CM` 重跑：任务从"预测血压"改为"预测弦/非弦"，
  指标从 ρ 改为 AUC + 物理量簇份额。**这一步才第一次真正回答"AI 想的中医对不对"。**

### 3.1 编码字典（照这个填，不要自由文本）

| 字段 | 取值 | 说明 |
|---|---|---|
| `pulse_main` | 弦 / 滑 / 涩 / 濡 / 紧 / 洪 / 细 / 平 / 其他 | 主脉，单值必填 |
| `pulse_sub` | 同上，可多值（`;` 分隔） | 兼脉，可空 |
| `depth` | 浮 / 中 / 沉 | 举按寻的层次 |
| `rate` | 迟 / 平 / 数 | 以 5 s 窗口内搏数折算，仅作粗判 |
| `force` | 有力 / 无力 | 脉势 |
| `confidence` | 高 / 中 / 低 | 判读者自评，低置信度样本后续单独分析 |
| `note` | 自由文本，≤50 字 | 只在必要时填（如"边界不清，疑似运动伪影"） |

### 3.2 判读注意事项（写给医生）

- 只看波形轮廓，**不要**根据体型、年龄"猜"脉象。
- 左右手分别判，不要求对称；六部不一致是正常现象，如实填。
- 遇到明显伪影（基线漂移、削顶、平段）填 `confidence=低` 并在 `note` 注明，
  **不要**勉强给主脉。
- 每人六部**独立判读**，不要先形成"这个人是什么脉"的整体印象再套到六部上。

## 4 T0 / T1：半天到两天的补充（可选但便宜）

### T0 标签审计（0.5 天）

逐人核对这 57 条血压是在什么条件下测的，填 `A0_bp_audit.csv`：

| 字段 | 取值示例 | 为什么重要 |
|---|---|---|
| `subject_id` | SUBJ-A | 主键 |
| `bp_datetime` | 2015-10-13 15:47 | 与仪器记录比对 |
| `method` | 水银 / 电子 / 仪器自带 | 不同方法系统偏差可达 5–10 mmHg |
| `arm` / `position` | 右 / 坐位 | 左右手差可达 10 mmHg |
| `rest_min` | 5 | 未静息会高估 |
| `medication` | 已服降压药 / 未服 / 不详 | 服药后血压不代表基础状态 |
| `white_coat` | 是 / 否 / 不详 | 白大衣效应可达 20 mmHg |
| `same_day_repeat` | 有（几点）/ 无 | **若有，直接进 T1** |

### T1 逐次血压摘录（1–2 天，仅在病历有多条记录时做）

- 检索范围：采集当日 ±24 h 内该患者的**全部**血压记录（门诊、病房、术前、术中）。
- 对齐规则：每条记录按时间贴到最近的采集段（左手段 / 右手段），
  `|bp_time − segment_time| ≤ 30 min` 才可用；超过则标 `usable=0`。
- 预期产出：多数人仍只有 1 条。**若最终每人的有效时点数 ≤1，本档作废，不要进入建模。**

## 5 T3 前瞻逐搏（唯一能得到逐搏血压的路径）

### 5.1 为什么回顾数据做不到

1. **没有连续血压参考**：CM 采集只有脉搏波，没有动脉线、没有 Finapres/Nexfin。
2. **人眼无法逐搏定标**：逐搏血压需要每次心搏的绝对压力，波形只能给相对形态；
   让医生"看波形标血压"本质是主观插值，产出的不是测量值。
3. **单段太短**：每段 5 s（约 6 搏），即使有连续参考也不足以做逐搏建模。

### 5.2 方案（20–30 例，单中心）

| 项 | 内容 |
|---|---|
| 受试者 | 18–80 岁，能配合；排除房颤、严重主动脉瓣病变、上肢动脉狭窄、采集部位皮肤破损 |
| 设备 | 指动脉连续压（Finapres NOVA / Nexfin 一类）+ 现有六部采集系统 + 袖带校准 |
| 流程 | 静息 10 min → 袖带校准 → 六部各 60 s → **握力试验 2 min**（或冷加压）→ 恢复 5 min |
| 为什么加诱发试验 | 静息 5 min 内血压变异 <5 mmHg，模型学不到东西；握力/冷加压可诱发 15–30 mmHg 变化，**制造真实动态范围** |
| 目标产出 | 每例约 600–900 搏，逐搏 SBP/DBP + 同步六部波形 |
| 伦理 | **需修正案**：新增采集、新增设备、新增知情同意；诱发试验有心血管风险，须由临床医生判定适应症并全程在场 |
| 风险控制 | 有高血压未控制、冠心病、主动脉瘤者排除；试验中连续监测、出现胸痛/明显头晕立即终止 |

### 5.3 样本量估算

- 以"逐搏 SBP 的个体内相关 ρ"为主指标：每人 600 搏、20 人约 12,000 搏。
- 若目标是"跨人泛化"（不给个体校准），20 人远远不够，需 ≥100 人；
  若目标是"个体内连续监测"（每人先校准再预测），20 人可分 10 训 10 测，**这是更现实的定位**。
- 建议先做 20 例验证可行性，再决定是否扩到 100 例。

## 6 质控与验收指标（写进交付条件）

| 指标 | 阈值 | 不达标怎么办 |
|---|---|---|
| 完整性：342 部有主脉的比例 | ≥95% | 补读缺失部 |
| 双读一致性：弦/非弦 Cohen's κ | ≥0.60 | 复盘分歧病例，重新培训后重读 |
| 判读者自身重测 κ（2 周后） | ≥0.70 | 说明口径不稳，需固定判读规则卡 |
| 时间对齐（T1）：`|Δ|≤30 min` 的比例 | ≥80% | 放宽到 1 h 并单独标记 |
| `confidence=低` 的比例 | ≤25% | 超了说明图像质量或判读口径有问题 |
| 盲法检查：判读者能否猜出血压高低 | 与真实 SBP 的 ρ 应 ≈0 | 若显著>0，说明图里泄露了信息，退回重做 |

## 7 拿到数据后，工程侧怎么接

1. `A2_pulse_read.csv` → `data/labels_cm_pulse.csv`（`subject_id, position, pulse_main, ...`）。
2. `probe_mediator.py` 的 CM 分支改为按 `(subject_id, position)` 取标签，任务二分类。
3. 重跑：`--sources CM --archs mlp,transformer --seeds 0,1,2`，指标加 AUC、敏感度/特异度。
4. 解剖结论只看一件事：**判"弦"时模型依赖的物理量簇，与 12 号在 VDB 上得到的"张力+反射"是否一致**。
   一致 → 模型的中医判断与物理机制同源；不一致 → 说明它靠的是别的捷径（须查明）。
