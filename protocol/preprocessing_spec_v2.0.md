# 多数据集统一处理规范 v2.0

生效：2026-10-31　　适用：PWDB / VitalDB / MIMIC-BP / CM 本地队列（未来任何新增源）
前身：v1.0（2026-10-30 首版）、v1.1（质量门修订）
原则：**任何跨数据集比较或联合训练，必须先通过本规范的关卡；任一道不通过，该比较/训练作废。**

---

## 0. 三条已踩过的坑（为什么需要这份规范）

| 坑 | 后果 | 现在怎么防 |
|---|---|---|
| 两个域用不同函数算同名特征 | 首轮迁移 ρ=+0.001，结论不可解释，全部作废 | §5 单一实现 + 哈希锁定 |
| 一个域按收缩峰对齐、另一个按足点对齐 | 真实队列 `aix_proxy` 实际量"周期末−周期初"，导致"反射波结构丢失"的错误结论 | §3 足点对齐为唯一合法约定 |
| **四源直接混在一起训练** | 留出 VDB 时 MAE 37.1，反而差于只用单源（35.1），**负迁移** | **v2.0 §12 融合三道门** |

## 1. 记录级要素（每段数据必须有）

| 字段 | 说明 | 缺失处理 |
|---|---|---|
| `dataset` | `PWDB` / `VDB` / `MIMIC` / `CM` | 必填 |
| `subject_id` | 受试者伪名（跨数据集加前缀，如 `VDB:1234`） | 必填 |
| `record_id` | 段/病例内唯一 | 必填 |
| `fs_native` | 原始采样率 | 必填 |
| `site` | 采集部位 | 缺失记 `unknown` |
| `unit` | `mmHg` / `au` | 必填 |
| `calibrated` | 是否有绝对压力标定（0/1） | 必填 |
| `quality` | 见 §6 | 由流程计算 |

---

## 2. 幅值与单位（决定能不能做"血压估计"）

- 一律转 mmHg 或明确标记 `au`。
- **`calibrated=0` 的数据禁止参与绝对压力回归**，只能进入形态分析。
- 绝对幅值特征（`pp_mmHg`、`mbp_mmHg`）单独成组，任何监督任务必须报 **CAL / UNCAL 两组结果**（判据 G2）。

| 源 | 单位 | 已标定 | 备注 |
|---|---|---|---|
| PWDB | mmHg | 是（仿真真值） | 最容易产生校准泄漏的源 |
| VitalDB `SNUADC/ART` | mmHg | 是（有创） | 含哨兵值 −495.6 与伪迹，见 §4 |
| MIMIC-BP `abp` | mmHg | 是（有创） | 125 Hz，30 s 段，见 §4 |
| CM 本地 | `au` | **否** | 25 通道压力阵列，通道语义未知 |

---

## 3. 心动周期分割（唯一合法约定：足点对齐）

- 足点检测：带通信号取 `find_peaks(-y, distance=0.33·fs, prominence=0.25·σ)`
- 禁止用收缩峰对齐（峰对齐会让周期末接上下一搏上升支，AIx 类指标系统性失效）
- 每搏重采样到 **NPH = 256**（相位归一化，与心率解耦），另存 `cyc_dur` 保留绝对时标
- 逐搏取**中位数**作为该段代表周期；同时记录 `beat_consistency`

## 4. 各源特有的清洗

| 源 | 问题 | 处理 |
|---|---|---|
| VitalDB | 哨兵值 −495.6、伪迹尖峰、长时缺失 | 掩掉 `<5` 或 `>250`；短缺口（≤0.1 s）线性插值；取最长连续段 |
| VitalDB | 单例可达 4 小时 | 读取上限 300 万行；逐搏抽样上限 2000 搏 |
| MIMIC-BP | 段长仅 30 s；个别段无有效搏动或越界 | 段长门豁免为 ≥25 s（§6）；`p99<20` 或 `p1>300` 或 `ptp<10` 的段跳过；不足 8 搏跳过 |
| CM 本地 | 8 bit 量化、逐搏形态畸变 | `seg_feats` 内做峰顶平台跳过（§5 注） |
| CM 本地 | 25 通道无标签语义 | 取心脏频带 SNR 最高通道；不假设空间含义 |
| PWDB | `plausibility==0` 的例 | 过滤 |

**峰顶平台问题（量化数据通用）**：`q=(p-min)/(max-min)` 后峰顶有多个并列 1.0，直接找局部极大导致 `aix=0`。须先跳过 `q > q[i1] − plat` 的平台段（`plat≈0.02`）。

## 5. 特征：单一实现 + 哈希锁定

- 唯一实现：`scripts/pwfeat.py::seg_feats()`
- 每次产出特征表必须把 `FEATURE_IMPL_SHA256` 写入 manifest（v2.0 实测 = `b5e46d7f9cff0e03…`）
- **禁止**在数据集脚本里自带特征副本

四组特征：

| 组 | 内容 | 用途 |
|---|---|---|
| `abs` | `pp_mmHg`, `mbp_mmHg` | 仅 CAL 协议 |
| `harm` | `h1..h8`, `h2_r..h8_r`, `hf_energy` | 僵硬度机制假设的核心载体 |
| `morph` | `t1,t2,t_notch,t_dicrotic,p2_rel,ap_rel,aix_proxy,notch_depth,width50,upstroke_slope,skew,kurt,q_entropy` | 形态学判据 |
| `tempo` | `cyc_dur`, `hr` | 心率相关 |

## 6. 统一质量门（所有源同一阈值）

| 门 | 阈值 | 依据 |
|---|---|---|
| 段长 | ≥ 60 s（**MIMIC-BP 豁免为 ≥25 s**，写入 manifest） | 保证搏数 |
| 有效采样占比 | ≥ 0.80 | 缺失过多则中位周期不可靠 |
| 主导心律保留率 `keep_frac` | ≥ 0.30 | 只保留 RR 偏离中位数 <35% 的搏 |
| 搏间一致性 `beat_consistency` | ≥ 0.85 | 基于保留搏计算 |
| RR 变异 `rr_cv` | 记录项，不作硬门 | 手术/ICU 记录本就心律不齐 |
| 脉压 | 15 ≤ PP ≤ 180 mmHg（仅 `calibrated=1`） | 生理范围 |
| 逐搏保留数 | ≥ 8 | 中位数稳健性下限 |

未通过的数据**不删除**，标 `quality=0` + `reason`，进入敏感性分析。
受试者级：`q_frac` = 通过段占比，`quality = 1 if q_frac ≥ 0.5`。

## 7. 标签体系（必须区分，禁止混用）

| `label_type` | 定义 | 可信度 | 允许用法 |
|---|---|---|---|
| `expert_tcm` | ≥2 位中医师盲评 | 高 | 监督目标与语义锚点 |
| `dx_code` | 病历诊断 | 中高 | 临床表型目标 |
| `proxy` | 规则派生 | **低** | 仅探索性；必须附 §8 效度检验 |

**v2.0 新增两个必填字段**（v1.1 及之前没有，导致 T2 曾出现循环论证风险）：

| 字段 | 取值 | 含义 |
|---|---|---|
| `y_htn_src` | `sim_truth` / `preop_htn(dx)` / `seg_measured(ABP)` / `cuff_threshold` | 标签来源 |
| `y_htn_indep` | 1 / 0 | **标签是否独立于波形**。0 = 由同一段波形派生，**禁止进入 T2 监督**（MIMIC 属此类） |

## 8. 代理标签效度检验（每个 proxy 强制）

1. 受试者级特征 → 代理标签，分层 5 折 AUC
2. 200 次标签置换零分布 → p 值
3. 单特征 AUC + bootstrap 95% CI
4. 协变量对照：仅年龄、仅 SBP 的 AUC
5. 样本量说明：n=57 时零分布 95 分位约 0.66，**只能排除 AUC>0.66 的效应**

**实测**：CM n=57 AUC=0.532 p=0.355；VDB n=1980 形态 0.582 vs 人口学 0.762、增量 −0.004；四源融合 T2 全 ≈0.50。→ 该 proxy 无信息量，保留为阴性对照。

## 9. 划分与泄漏控制

| 场景 | 划分方式 | 禁止 |
|---|---|---|
| 同源内评估 | 受试者级 K 折（同人多段必须同折） | 按记录随机划分 |
| 跨源迁移 | 整源留出（LODO） | 混合后随机划分 |
| 参数网格数据（PWDB） | 额外报"参数层外推"（训练 −1/0 档，测 +1 档） | 只报内插 |
| **MIMIC-BP** | **官方 `test_subjects.txt`(229) 永不进训练** | 自行重划 |

## 11. 统一语料的三层判定（v2.0 核心）

跨源"统一"必须分三层独立判定，混为一谈会得出错误结论：

| 层 | 判定标准 | 实测 | 结论 |
|---|---|---|---|
| **波形层** | 同实现、同足点、同重采样、同质量门 | 四源 18,630 条全部产出同 schema | ✅ 可统一 |
| **标签层** | 语义可通约 且 `y_htn_indep=1` | 四源语义互不相同，MIMIC 为 0 | ❌ 不可统一，须分层保留 |
| **特征层** | 跨源域分类 AUC < 0.95 | 两两 0.956–1.000，34/34 特征 \|SMD\|>0.8 | ⚠️ 仅 11 维形状比值子集可用 |

## 12. 融合三道门（v2.0 新增，硬约束）

任何"把多个源合起来训练"的尝试，必须依次通过：

### G10 负迁移门

> 全融合模型在留出域上的 MAE 必须 **≤ 该域的最佳单源模型**。

不通过即判负迁移，**禁止**以"数据更多"为由强行全融合。

实测（Ridge + `zsrc`，34 维全特征）：VDB 37.14 vs 单源 35.14（**FAIL**，Δ=+2.00）；CM 25.73 vs 22.90（**FAIL**，Δ=+2.83）。
改用 11 维形状比值子集后：VDB **19.70**，全融合即最优（**PASS**）。

### G11 源可混性门

> 拟混训的任意两源，形态特征域分类 AUC 必须 < 0.95。

实测：CM–PWDB 1.000、PWDB–VDB 1.000、MIMIC–PWDB 1.000、MIMIC–VDB 0.993、CM–MIMIC 0.974、CM–VDB 0.956 → **全部 FAIL**。
含义：四源在特征空间里几乎完全可分，"学共享机制"的前提不成立；融合的收益只能来自数据量，不能来自机制共享。

### G12 校准单调性门

> 增加校准样本数不应使评估误差上升。

实测：CM 25.73→19.22（k=1）✅；MIMIC 21.83→16.87（k=10）✅；**VDB 37.14→41.51（k=1）❌**。
不通过说明该域的跨域预测本身无排序信息（VDB 跨域 ρ≈0.00），此时任何线性校正都只是放大噪声。

**校准实现约定**：优先用**仅偏置校正**（中位数残差平移）；小样本仿射校准（k≤5 拟合斜率）会方差爆炸，VDB 上曾出现 37.1→65.7 的恶化。

---

## 13. 推荐做法（过了三道门之后）

按优先级：

1. **11 维形状比值子集 + 全融合**（安全，无负迁移）
2. **源组合消融选最小充分源集**（每个目标域单独选，误差再降 0.5–1.5 mmHg）
3. **加 1 个目标域受试者做偏置校正**（成本最低、收益最大：CM −6.5 mmHg）
4. 不足：绝对精度仍在 19–26 mmHg，**不足以支撑临床 SBP 估计**，只能支撑"相对排序 + 一次校准"
